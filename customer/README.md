# Клиентская часть Kapouch

Папка `customer/` специально не использует админский `inc/layout.php`, не обращается к базе напрямую и не требует PHP на клиентском сайте. Витрина — обычные HTML/CSS/JS.

## Что уже работает

Поток: каталог → корзина → самовывоз → заказ в live-экране бариста → публичное отслеживание статуса.

Клиентская часть обращается только к публичному API Kapouch:

- `GET customer_catalog.php`
- `POST customer_order.php`
- `GET customer_order_status.php?token=...`

Сервер сам повторно проверяет товары, доступность и цены. Браузер передаёт только ID товара и количество, поэтому итоговую сумму нельзя подменить на клиенте.

Оформление идемпотентное: браузер передаёт случайный `client_order_id`, и повтор одного и того же запроса не создаёт второй заказ.

## Лояльность MVP

Миграция 017 создаёт клиентов, журнал бонусных операций и связь заказа с клиентом.

По умолчанию после статуса «Выдан» начисляется 5% от суммы заказа. Процент хранится в `app_settings` под ключом `customer_loyalty_percent` и ограничен диапазоном 0–50%.

Начисление выполняется существующим `cron/online_orders_sync.php`, поэтому при его минутном запуске бонусы появляются максимум примерно через минуту после выдачи. Повторное начисление одного заказа защищено полем `loyalty_earned_at`.

Списание бонусов и подтверждённый вход по телефону пока не включены — это следующий этап. До появления SMS/OTP нельзя безопасно разрешать тратить баланс только по введённому номеру телефона.

## Перенос на другой домен

1. Скопировать содержимое `customer/` на новый сайт.
2. В `customer/config.js` заменить `apiBase` на абсолютный адрес Kapouch, например `https://kapouch.store`.
3. В Kapouch задать `customer_api_allowed_origin` равным origin клиентского сайта, например `https://order.example.ru`.

После этого клиентский интерфейс может жить отдельно, а каталог, заказы, статусы и лояльность останутся в Kapouch.

## Безопасность статуса

Публичное отслеживание использует случайный 64-символьный `tracking_token`, а не внутренний ID или легко угадываемый номер заказа.
