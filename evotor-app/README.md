# Kapouch Orders для Эвотор

Небольшое Android-приложение для смарт-терминала Эвотор. Оно принимает адресные push-уведомления Облака Эвотор и показывает новые клиентские заказы Kapouch как системные уведомления со звуком и вибрацией.

## Что потребуется

1. В кабинете разработчика Эвотор создать приложение **с APK**.
2. Пакет приложения в кабинете должен быть `ru.kapouch.evotor`.
3. Скопировать UUID приложения (Application ID).
4. Создать ключ издателя и дать ему право `push-notification:write`.
5. Узнать UUID нужного смарт-терминала или его IMEI.
6. Собрать APK с реальным UUID приложения: `gradle -p evotor-app :app:assembleDebug -PEVOTOR_APP_UUID=<UUID>`.
7. Загрузить APK в черновик приложения Эвотор и установить его на тестовый терминал.
8. В Kapouch → Интеграции → Эвотор заполнить Application ID, UUID/IMEI терминала и ключ издателя, затем нажать «Отправить тест на экран».

## Два независимых выключателя

- В Kapouch можно полностью отключить отправку уведомлений в Облако Эвотор.
- В приложении Kapouch Orders на самом терминале можно выключить только показ уведомлений на этом устройстве. Полученное сообщение всё равно сохранится как последнее, но системное уведомление не появится.

Секретные ключи не должны попадать в репозиторий. Ключ издателя вводится только через настройки Kapouch и хранится в зашифрованном виде.
