# Public legal footer

Клиентская PWA показывает правовые документы на главной странице без авторизации. Футер содержит ссылки на политику конфиденциальности, публичную оферту, реквизиты продавца и банковские реквизиты. Политика конфиденциальности публикуется через общий публичный legal API и использует реквизиты продавца из настроек Kapouch.
