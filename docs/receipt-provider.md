# Источник электронных чеков для QR-закупок

QR кассового чека содержит фискальные реквизиты, но не полный список товаров. Для автоматического прихода Kapouch после сканирования QR обращается к настроенному HTTPS endpoint.

Kapouch вызывает endpoint методом `GET` и передаёт query-параметры:

- `fn` — номер фискального накопителя;
- `fd` — номер фискального документа;
- `fp` — фискальный признак;
- `t` — дата/время из QR;
- `s` — сумма чека в рублях;
- `n` — признак расчёта.

Если в настройках указан Bearer token, Kapouch добавляет `Authorization: Bearer <token>`.

Endpoint должен вернуть JSON электронного чека. Поддерживаются распространённые структуры:

```json
{
  "ticket": {
    "document": {
      "receipt": {
        "user": "ООО Поставщик",
        "userInn": "1234567890",
        "fiscalDriveNumber": "...",
        "fiscalDocumentNumber": 123,
        "fiscalSign": 456,
        "dateTime": "2026-09-04T10:30:00",
        "totalSum": 124500,
        "items": [
          {"name":"Молоко 0,93 л","quantity":12,"price":9500,"sum":114000},
          {"name":"Сироп 1 л","quantity":1,"price":10500,"sum":10500}
        ]
      }
    }
  }
}
```

Для FNS-style полей `price`, `sum`, `totalSum` суммы считаются копейками. Более простой JSON также поддерживается: `receipt.items`, `items[].unit_price`, `items[].line_total`, `total_amount` — в рублях.

## ФНС России

У ФНС есть сервис «Открытое API проверки чека ККТ», но доступ к нему выдаётся внешним пользователям после регистрации и получения мастер-токена. Условия ФНС также ограничивают цели использования сервиса. Поэтому Kapouch не содержит неофициальных ключей и не обходит процедуру доступа ФНС.

Для рабочего автоматического импорта следует использовать источник данных, на использование которого у владельца Kapouch есть право: собственный разрешённый адаптер к ФНС, API ОФД/поставщика или другой договорный сервис электронных чеков.

До подключения endpoint можно использовать резервный импорт JSON в интерфейсе «Закупки → Сканировать QR-чек»; вся логика сопоставления и прихода работает одинаково.
