# Эвотор: HTTP 403

Если MyCoffee получает `HTTP 403` от `api.evotor.ru`, проверьте:

1. Приложение Эвотор установлено в личном кабинете того же пользователя, для которого получен токен.
2. Черновик/версия приложения переведена в тестирование или опубликована.
3. У приложения включены необходимые разрешения на чтение магазинов, товаров и документов.
4. Используется токен Облака Эвотор, уникальный для пары приложение-пользователь, а не токен издателя/OAuth от кабинета разработчика.
5. Исходящие REST-запросы передают токен в заголовке `Authorization`.

По документации Эвотор код 403 означает, что приложению не разрешено запрашиваемое действие либо приложение не установлено пользователем.
