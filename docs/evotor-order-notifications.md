# Уведомления о новых заказах Kapouch на Эвоторе

Kapouch использует официальный Cloud Push API Эвотор. Сервер отправляет адресное сообщение приложению **Kapouch Orders**, установленному на конкретном смарт-терминале.

## 1. Создать приложение в Эвотор

На Портале разработчиков Эвотор создайте приложение для платформы Эвотор и включите вариант **«Приложение с APK»**.

Для Android-приложения Kapouch используются:

- package/application ID: `ru.kapouch.evotor`;
- `app_uuid`: Application ID, который выдаёт Портал разработчиков Эвотор.

Настоящий `app_uuid` не хранится в репозитории. Он подставляется при сборке APK.

## 2. Получить ключ издателя

Создайте персональный ключ доступа издателя с разрешением на передачу push-уведомлений (`push-notification:write`). Это отдельный секрет: пользовательский токен Эвотор, который Kapouch уже использует для синхронизации магазина, его не заменяет.

Ключ издателя вводится только на странице **Kapouch → Интеграции → Эвотор**. После сохранения Kapouch хранит его зашифрованным и больше не показывает целиком.

## 3. Собрать и установить APK

Workflow **Evotor APK** собирает приложение. Для реальной установки запустите его вручную (`workflow_dispatch`) и передайте настоящий Application ID в параметре `evotor_app_uuid`.

Полученный APK загрузите во вкладку APK созданного приложения Эвотор и установите на тестовый терминал. Package ID в кабинете разработчика должен совпадать с `ru.kapouch.evotor`.

## 4. Настроить Kapouch

В блоке уведомлений подключения Эвотор укажите:

- Application ID (`app_uuid`);
- UUID смарт-терминала или его 15-значный IMEI;
- ключ издателя;
- включите переключатель «Отправлять уведомления о новых заказах на экран Эвотор».

После сохранения нажмите **«Отправить тест на экран»**.

## Когда отправляется уведомление

- Наличные: после успешного создания заказа.
- СБП: только после того, как ЮKassa подтверждает оплату и заказ переходит из `awaiting_payment` в `new`.
- Повторный запрос того же заказа, повторный webhook или polling не создают дубль: сочетание терминал + заказ + тип события уникально в журнале.
- Ошибки доставки не ломают checkout. Недавние ошибки повторяются cron-задачей до пяти попыток.

## Два независимых выключателя

1. **Серверный** в Kapouch — полностью прекращает отправку push в Облако Эвотор.
2. **Локальный** в приложении Kapouch Orders на терминале — приложение продолжает получать и запоминать последнее сообщение, но не показывает системное уведомление, звук и вибрацию на этом Эвоторе.

Так можно временно отключить экранные уведомления на одной кассе, не меняя общую серверную настройку.
