# Проверка токена Эвотор

Для MyCoffee нужен токен Облака Эвотор, который создаётся для пары «приложение — пользователь» после установки приложения в Личном кабинете Эвотор.

Чек-лист:

- приложение создано в кабинете разработчика Эвотор;
- версия/черновик переведена в тестирование;
- аккаунт владельца добавлен как тестировщик, если приложение ещё не опубликовано;
- приложение установлено в обычном Личном кабинете владельца Эвотор;
- токен получен через вкладку «Настройки» установленного приложения либо автоматически через endpoint передачи токена;
- приложению выданы права на ресурсы, которые использует MyCoffee: магазины, товары и документы;
- токен вводится только в MyCoffee → Интеграции → Эвотор и не сохраняется в GitHub.
