# MyCoffee visual direction

Цель интерфейса: строгий современный SaaS для владельца бизнеса.

Принципы:
- холодные нейтральные поверхности вместо бежево-кофейной палитры;
- графитовый сайдбар;
- один основной синий акцент;
- зелёный/красный только для статусов и отклонений;
- меньше теней, меньше декоративных градиентов;
- скругления умеренные;
- повышенный контраст таблиц, KPI и форм;
- графики и их структура сохраняются.
